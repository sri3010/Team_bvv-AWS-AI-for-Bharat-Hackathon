# Project Context: AI-Powered Agricultural Assistant System

## Project Overview
This is an AI-powered agricultural assistant system built for the AWS AI for Bharat Hackathon by Team BVV. The system empowers Indian farmers with voice-first interfaces, crop disease detection, market insights, and financial planning tools.

## Key Technologies
- **AWS Services**: Amazon Bedrock, Lambda, S3, Rekognition, Polly, Transcribe
- **Communication**: Twilio for voice calls
- **Frontend**: React Native (mobile), React.js (web)
- **Backend**: Python 3.11+ with serverless architecture

## Core Modules
1. **Voice Buddy**: Voice-based conversation system
2. **Crop Guardian**: AI-powered disease detection
3. **Market Insight**: Price prediction and market analysis
4. **Profit Planner**: Financial planning and tracking

## Development Guidelines
- Follow serverless-first architecture
- Optimize for low-bandwidth rural connectivity
- Support multiple Indian regional languages
- Prioritize voice-first user experience
- Ensure data privacy and security

## AWS Best Practices
- Use IAM roles with least privilege
- Enable encryption at rest and in transit
- Implement proper error handling and logging
- Use CloudWatch for monitoring
- Follow Well-Architected Framework principles
