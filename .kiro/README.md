# Kiro Configuration

This directory contains Kiro IDE configuration for the AI-Powered Agricultural Assistant System project.

## Directory Structure

```
.kiro/
├── settings/           # Workspace and project settings
│   └── workspace.json  # Project configuration
├── steering/           # AI assistant context and guidelines
│   └── project-context.md  # Project-specific context for Kiro
└── README.md          # This file
```

## Purpose

The `.kiro` directory is used by Kiro IDE to:
- Understand project context and structure
- Provide relevant AI assistance
- Apply project-specific coding standards
- Enable intelligent code suggestions

## AWS AI for Bharat Hackathon

This configuration is part of our submission for the AWS AI for Bharat Hackathon, demonstrating the use of Kiro IDE in building AI-powered solutions for Indian farmers.
